# Multiple Pilots Report Erratic Flashing Object at Extreme Altitude

**FAA · 2023**

> This FAA incident report from November 2023 documents multiple aircraft crews observing an unidentified aerial phenomenon with flashing lights at altitudes far above normal flight ceilings. The object was reported changing altitude erratically between roughly 50,000 and 90,000 feet, and the case was closed with no follow-up investigation detailed.

On 9 November 2023 at 02:55, the FAA's Memphis Air Route Traffic Control Center (ZME) logged an incident under its SKYWATCH system — a programme for tracking unidentified aerial phenomena. The report was filed under code "Unidentified Aerial Phenomenon" and later closed without any public follow-up.

Multiple aircraft at different altitudes — 28,000, 34,000, and 45,000 feet — independently reported observing the same unknown object. The phenomenon was described as having flashing lights and changing altitudes erratically. Its position was logged at a navigational fix designated ARG324080, with an altitude range between FL500 and FL900 — that is, between roughly 50,000 and 90,000 feet. Both of those figures are well above the ceiling of typical commercial aircraft, which generally fly no higher than about 43,000 feet.

The report is a single page. It contains no radar data, no sensor corroboration, and no aircraft identifiers for the crews who made the reports. The geographic location is referenced only by a radial/distance fix (ARG324080) and the Denver point of departure code (DEN), with no plain-language place name given. The case status is listed as "Closed," with no indication of further investigation or any conclusion about what the object was.

## What to know

- The claimed altitude range (50,000–90,000 feet) is far above where commercial aircraft operate, but this report contains no radar data or sensor readings to corroborate it — it is based solely on pilot observations.
- The report is a single closed page with no follow-up, no analysis, and no conclusion about what was observed.
- No aircraft identifiers are included, so the independent pilot reports cannot be cross-checked against flight records from this document alone.
- The geographic location is given only as a navigational fix code (ARG324080), not a named place, making it difficult to pin down exactly where this occurred.
- This is an administrative incident log, not an investigation report — it records what was reported but does not evaluate or explain it.
