# U.S. Military Report Documents Balloon-Like Object Over Arabian Gulf

**Department of War · N/A**

> A 2020 U.S. military mission report describes a military operator tracking an unidentified object over the Arabian Gulf that resembled a balloon drifting with the wind at about 31,000 feet. The object produced a strong enough sensor return to be classified as a weapons-quality track, but the report is heavily redacted and no formal identification was made.

This document is a U.S. Department of War mission report from 2020, originally classified SECRET, describing an encounter with an unidentified anomalous phenomenon (UAP) in the Arabian Gulf region. The report was filed by a single military operator.

The operator observed an object that, in their words, "looks like a balloon" and was "traveling with the winds" at approximately 31,000 feet above sea level. The object was noted as similar to a UAP previously reported by the 48th Fighter Wing, suggesting this was not a one-off sighting. The operator tracked the object as a "weapons quality 1 track" — meaning the sensors produced a reliable enough return that the object could theoretically have been engaged as a target. The operator confirmed they achieved a targeting solution (described as "next to shoot") and visually identified the object using the aircraft's targeting forward-looking infrared (TFLIR) sensor, an infrared camera used for precision targeting.

Despite this detailed tracking, the document does not contain a formal conclusion about what the object was. The operator's own description — balloon-like, wind-driven, not self-propelled — points toward something conventional, but no definitive identification appears in the unredacted portions.

Significant portions of the report are redacted under classification markings for national security information. Full location coordinates, operational details, and potentially important context are blacked out, making it impossible to independently verify the full scope of the encounter from this document alone.

## What to know

- This is a single-source report from one military operator — no corroborating observer or additional sensor data is visible in the unredacted text.
- The report is heavily redacted: multiple sections are fully obscured under national security classification markings, hiding potentially significant details.
- The operator's own description ('looks like a balloon,' 'traveling with the winds') suggests a mundane object, but no formal identification or resolution is provided in the visible text.
- Partial coordinates are visible but the full location is redacted, preventing independent verification of where the encounter took place.
- The reference to a prior similar UAP from the 48th Fighter Wing suggests a pattern, but no details of that earlier sighting are included in this document.
