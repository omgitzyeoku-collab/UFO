How corrections are processed

  1. You open a GitHub issue using the correction template.
  2. We verify the claim against the source PDF (and external sources where relevant).
  3. If verified, the public document page gets corrected, the original wrong text is preserved here in the log alongside the fix, and the correction is timestamped.
  4. If we can't verify the correction, we explain why in the issue thread and close it.

This log is also available as machine-readable JSON: extract/corrections.jsonl (empty until first correction).
