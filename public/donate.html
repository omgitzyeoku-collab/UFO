Support UAP Files

UAP Files is free for everyone. No paywalls, no ads, no signups, no tracking. It will stay that way.

If the project is useful to you, donations cover the running costs and let me keep adding sources.

One-time donation

The simplest way: a one-time donation via Stripe / PayPal / crypto.

  • Stripe (card / Apple Pay / Google Pay) — link coming once Stripe Connect is set up.
  • PayPal — link coming.
  • Crypto (BTC / ETH / SOL) — addresses coming.

Recurring support

  • Open Collective — transparent project funding, public ledger. Coming.
  • GitHub Sponsors — coming.

What donations cover

  • Compute — the QA pipeline runs millions of LLM tokens per tranche; this is the biggest line item.
  • Hosting + bandwidth — Cloudflare Pages, GitHub Releases, custom domain.
  • OCR — for very large scanned archives (FBI Vault is gigabytes).
  • Time — maintaining the pipeline, adding new sources, responding to error reports.

For institutions

If your institution (university, NGO, research org) wants to sponsor the project, contact us — we offer named-acknowledgement on the about page and priority access to the upcoming API.

API access for journalists / researchers

Coming soon: a low-cost API tier ($20/month) for bulk access. Free tier covers light use (1000 calls/day). The data itself stays free in the GitHub Release; the API is for convenience.

What we will NEVER do

  • Run ads.
  • Paywall content.
  • Sell, share, or track user data.
  • Take money from anyone whose involvement would compromise editorial neutrality (governments, defence contractors, media outlets with active UAP coverage).
