# FAA logged unidentified object near Fort Myer in June 2021

**FAA · 2023**

> This is an FAA SKYWATCH incident report from 4 June 2021 documenting an unidentified aerial phenomenon spotted near Fort Myer, Virginia. Arlington County Police reported an object — tentatively described as a large balloon — travelling eastbound at roughly 600 to 1,000 feet. The case was closed with no public explanation of what the object was.

This document is an FAA (Federal Aviation Administration) incident report filed under the agency's SKYWATCH system, which logs unidentified aerial phenomena in US airspace. It carries the case number 237UAP00053 and is classified under the primary code "Unidentified Aerial Phenomenon."

On 4 June 2021 at 15:02, Arlington County Police Department reported an unidentified object in the Fort Myer area to the FAA via DCA — the reporting facility code for Reagan National Airport. Fort Myer is a military installation adjacent to the Pentagon in Arlington, Virginia, placing this sighting squarely in some of the most restricted airspace in the country.

The object was described as "possibly a large balloon" travelling eastbound at an estimated altitude of 600 to 1,000 feet. That phrasing — "possibly" — is the reporter's tentative guess, not a confirmed identification by the FAA or any other agency.

The case status is listed as "Closed." No follow-up investigation details, resolution, or final determination of what the object was appear in the document. There is no mention of corroborating radar data, pilot reports, or sensor evidence beyond the single police report.
