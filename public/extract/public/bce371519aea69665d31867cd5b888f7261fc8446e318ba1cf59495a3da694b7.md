# Multiple Pilots Report Bright, Rocket-Like Object Over Texas

**FAA · 2023**

> This FAA incident report documents an unidentified aerial phenomenon observed by crews aboard multiple aircraft near Junction, Texas on 16 March 2024. The bright, smoke-trailing object ascended past 36,000 feet and appeared to break apart, but was never detected on radar. The case was closed without identification.

On 16 March 2024 at 01:57, crews aboard multiple aircraft flying near the JCT VOR (a navigation point near Junction, Texas) reported an unidentified aerial phenomenon to air traffic control. The pilots described a very bright object trailing smoke, moving from west to east, which they believed resembled some type of rocket.

According to the report, the object passed from below the aircraft to above them — placing it at or above 36,000 feet — and then appeared to break up into pieces or disappear. Despite being reported at that altitude by multiple witnesses, the object was not detected on the air traffic control radar system.

The incident was logged under the FAA's SKYWATCH programme, which tracks unidentified aerial phenomena. NORAD (the North American Aerospace Defense Command) was notified. Houston Center (ZHU), the FAA facility handling the airspace, filed a Mandatory Occurrence Report and noted that FALCON radar replay data would be attached, though that radar data is not included in this document.

The FAA classified the primary code as "Unidentified Aerial Phenomenon" and marked the case status as closed. No resolution or identification of the object is recorded in the report.

## What to know

- This is a single-source FAA internal report based on verbal pilot accounts — there is no independent sensor confirmation of the object.
- The object was not detected on ATC radar, so there is no independent data on its altitude, speed, or trajectory.
- The pilots' description of the object as 'some type of rocket' is their interpretation, not a confirmed identification.
- FALCON radar replay data was referenced as an attachment but is not included in this document, so the radar record cannot be reviewed here.
- The case was closed with no explanation or identification recorded — 'closed' does not mean 'resolved'.
