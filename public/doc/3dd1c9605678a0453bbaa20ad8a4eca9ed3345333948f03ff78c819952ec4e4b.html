Five Airliners Spotted Same Unidentified Object Near Tampa in 2023

FAA 2023 ✓ verified against source

This FAA SKYWATCH incident report documents a November 2023 sighting in which five commercial aircraft crews independently observed a white, aircraft-sized object northwest of Tampa, Florida, at roughly 25,000–31,000 feet. The object did not appear on air traffic control radar, no aircraft took evasive action, and the case was closed without identifying the object.

On the evening of 19 November 2023, at 22:50, crews aboard five separate commercial flights reported seeing the same white object in the sky northwest of Tampa International Airport (TPA). The object was described as roughly the size of an aircraft, hovering or moving at altitudes between FL250 and FL310 — aviation shorthand for approximately 25,000 to 31,000 feet. The initial report was filed under callsign ASA516. Despite being seen by multiple independent flight crews, the object did not show up on the Federal Aviation Administration's air traffic control (ATC) radar systems. This is one of the more striking details in the report: a visual sighting corroborated by five aircraft, with no matching radar return. No pilots reported taking evasive manoeuvres, and the FAA noted no impact to flight operations. The report was classified under the FAA's primary code for "Unidentified Aerial Phenomenon" and processed through the SKYWATCH incident reporting system. The case status is listed as "Closed." The document provides no explanation or identification of the object. No crew names, aircraft tail numbers, or detailed witness statements appear in this summary-level report.

What to know

  • This is a summary-level FAA incident report, not a full investigation file — no witness statements, photographs, or supplementary data are included.
  • The object was visually reported only; it was not detected on ATC radar, meaning there is no independent sensor confirmation.
  • The case is marked 'Closed' with no resolution — the FAA did not identify the object or provide an explanation in this document.
  • No crew names or aircraft tail numbers are included, so independent verification of the witness accounts is not possible from this document alone.
  • The location reference 'LAL306084' is an FAA navigation fix; its precise position requires an aviation chart to pinpoint.
