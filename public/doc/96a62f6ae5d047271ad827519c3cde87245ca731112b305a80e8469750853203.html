FBI Cover Page From Newark Office Reveals Almost Nothing

FBI August 1952-1967 New Jersey, United States ± partially verified

This document is a single cover page from an FBI file associated with the Newark Field Office, spanning 1952 to 1967. The page is so heavily degraded or redacted that no substantive information about UFO sightings can be read from it — only the FBI letterhead and a note that it was copied for background-check processing are legible.

This record, catalogued as FBI-UAP-D012, is a cover page or file folder sheet from the Federal Bureau of Investigation's Newark Field Office. According to the metadata, the underlying file relates to events in New Jersey between August 1952 and 1967, but the extracted content tells a far thinner story. The document is classified as an image (IMG type), meaning it was scanned rather than born-digital. The scan quality is extremely poor. The only text that can be reliably read identifies it as a "Department of Justice, Federal Bureau of Investigation" document and notes that it was "COPIED FOR — EQIP," referring to the Electronic Questionnaires for Investigations Processing system, a government platform used for background checks. No names, no places, no descriptions of sightings, and no agency conclusions appear in the extracted text. The metadata catalogue describes extensive UFO sighting records from New Jersey across a fifteen-year span, but none of that content survived the extraction process. Whether that gap is due to extreme redaction, image degradation, or the fact that only the cover sheet was captured is not clear from the document alone. In short, this release puts a file on the public record without making its contents accessible. The cover page confirms the file exists within FBI holdings, but everything behind it remains unreadable.

What to know

  • This is a single cover page, not the full file. The multi-page content behind it was not successfully extracted or made available.
  • The document shows signs of extreme degradation or redaction — virtually no substantive text is legible beyond the FBI letterhead and the EQIP copy notation.
  • The metadata describes UFO sighting records from New Jersey (1952–1967), but none of that information appears in the actual extracted document text.
  • No witness names, sighting descriptions, or agency conclusions can be verified from this document alone.
  • The EQIP notation indicates the file was copied for background-check purposes, not necessarily released as part of a UAP disclosure effort.
